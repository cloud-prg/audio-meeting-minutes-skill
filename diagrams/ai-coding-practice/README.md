# AI Coding 实践工作流图

本目录收录「我的 AI Coding 实践工作流」示意图：从澄清需求、把 Spec 写进仓库、拆成可单独验收的 Ticket，到按难度选模型执行、对照 Spec/Ticket 检查，再以 PR/演示交付并回写 CONTEXT。核心原则是 **状态写在仓库，不写在聊天里**。

流程概览：

1. 澄清需求（目标 / 验收 / 约束 / 非目标）
2. 写 Spec 进仓库，可对照验收
3. 拆 Ticket：小步可完成、可单独验收
4. 选模型干：难 → 强模型，简 → 便宜模型
5. 对照 Spec 与 Ticket 检查
6. 交付回写：PR / 演示，更新 CONTEXT

下一张 Ticket 回到第 3 步，CONTEXT 带着走。卡住时先定位层：验收不对看 Spec，太大再切 Ticket，失忆补 CONTEXT，太贵则降模型。

## 文件

- `ai-coding-practice.excalidraw`：可编辑的 Excalidraw 源文件
- `ai-coding-practice.png`：预览图，便于在 GitHub 上直接查看，无需打开编辑器

## 如何打开 `.excalidraw`

1. 打开 [https://excalidraw.com](https://excalidraw.com)
2. 使用左上角菜单打开文件，或把 `ai-coding-practice.excalidraw` 拖放到页面中
3. 即可在浏览器中查看和编辑

也可在支持 Excalidraw 的 VS Code / Cursor 插件中打开同一文件。
